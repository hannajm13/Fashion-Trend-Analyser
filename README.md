# Fashion Trend Analysis & Forecasting

A web-based application for extracting, analysing and forecasting fashion trends from online fashion articles and blogs. Built as part of a Final Year Project, the app uses a fine-tuned transformer-based Named Entity Recognition (NER) model to identify fashion attributes from text and visualises their temporal evolution and predicted short-term future popularity.

---

##  Getting Started

### Prerequisites
Make sure you have Python installed along with the required dependencies. Install them with:

```bash
pip install -r requirements.txt
```

### Launch the App

```bash
streamlit run app.py
```

## NER Model

Fashion attributes are extracted using a fine-tuned **DeBERTaV3-base** model trained on a manually annotated dataset of fashion articles.

- **Task:** Named Entity Recognition (NER)
- **Base model:** `microsoft/deberta-v3-base`
- **F1-score:** 89.02%

### Entity Labels

| Label | Description | Examples |
|---|---|---|
| `ITEM` | Wearable products, clothing categories, accessories and footwear | *trench coat, ballet flats* |
| `BRAND` | Fashion houses, labels and retailers | *Gucci, Nordstrom* |
| `COLOR` | Basic colours, specific shades and composite colour descriptors | *butter yellow, monochrome* |
| `MATERIAL` | Fabrics, fibres and leather types | *leather, cable knit* |
| `PATTERN` | Visual motifs, prints and surface designs | *floral, animal print* |
| `STYLE` | Fashion aesthetics, movements, cultural eras and silhouette descriptors | *quiet luxury, Y2K* |
| `SEASON` | Calendar and fashion season references | *Fall/Winter, early fall* |
| `PRODUCT` | Commercial product names and signature items | *Birkin bag, Adidas Samba* |
| `DETAIL` | Garment construction, fit, neckline, finish and embellishment descriptors | *puff sleeves, wide-leg* |

## Data Sources

Articles were scraped from seven online fashion publications:
**Vogue, Harper's Bazaar, Elle, InStyle, Cosmopolitan, Who What Wear** and **The Zoe Report**.

All articles were published between **August 2025 and January 2026**.

---

## Limitations

- Trends reflect Western and predominantly US-based fashion publications.
- Forecasts are based on six monthly observations and may appear conservative.
- The app does not support real-time article input due to the computational requirements of DeBERTaV3-base.
